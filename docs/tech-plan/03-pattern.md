# 技术方案：格局判定模块（P1）

> **文档用途**：供 AI 开发执行。本文档描述"做什么"和"做到什么标准"，不描述"怎么写代码"。

---

## 一、目标

在合盘详情中展示每个人的**八字格局**（如"杂气正官格"、"偏印格"）。格局是八字命理的高阶概念，用于描述八字整体的"气质"，是专业感的重要来源。

---

## 二、技术方案（高层次）

### 2.1 什么是格局

格局 = 以**月令**（月支）为核心，结合天干透出情况，判定八字的主导十神类型。

**一句话**：看月支里藏了什么十神，那个十神在天干上有没有"透出来"，透出来就叫"成格"。

### 2.2 格局判定步骤（算法描述）

1. **取月令**：从月柱地支获取（如五月生人，月柱为"壬午"，月令为"午"）
2. **查月令藏干**：根据地支藏干表，获取月令的所有藏干（主气、中气、余气）
3. **计算藏干十神**：对每个藏干，计算它相对于日主的十神
4. **检查透出**：检查这些十神对应的天干是否在四柱天干中透出（即出现在年干、月干、日干、时干）
5. **确定格局**：
   - 如果透出，取透出的十神为格局
   - 如果没有透出，取主气十神为格局（不透也可成格）
6. **特殊规则**：
   - 如果月令是辰戌丑未（四库），格局名加"杂气"前缀
   - 如果日主 = 月令（如甲日生寅月），为"建禄格"
   - 如果月令是日主阳刃（甲卯、丙午、庚酉、壬子），为"羊刃格"

### 2.3 数据结构变化

**当前**：`BaziData` 没有格局字段。

**改造后**：`BaziData` 新增 `pattern: str` 字段（如"杂气正官格"）。

## 五、AI 开发约束（禁止清单）

### ❌ 禁止做的事情

1. **禁止只实现部分格局**：至少要支持正官、七杀、正印、偏印、食神、伤官、正财、偏财 8 种基本格局。
2. **禁止忽略杂气格**：月令是辰戌丑未时，必须加"杂气"前缀。
3. **禁止不透就不判格**：如果藏干没有透出天干，取主气十神为格局，不能返回空字符串。
4. **禁止修改十神计算逻辑**：格局判定依赖十神计算，但不要重写十神计算（用 `01-shishen.md` 的结果）。
5. **禁止添加无关功能**：不要加"格局解读"、"格局配对"等功能（那是 P2 的内容）。

### ✅ 必须做的事情

1. **必须完整实现格局判定算法**：按上述 6 个步骤，不能偷工减料。
2. **必须处理特殊格局**：建禄格、羊刃格至少要判断（可以不展示，但要计算）。
3. **必须在 `paipan.py` 中集成**：不能只写函数不调用。
4. **必须前端展示**：不能只算出来不展示。
5. **必须写测试**：至少测试 3 种不同的格局类型。

## 六、常见错误（AI 容易犯）

1. **藏干表不完整**：导致格局判定错误。→ 解决：复用 `01-shishen.md` 的地支藏干表，不要重新写。
2. **透出判断错误**：如月令藏干有"甲"，但"甲"在时干，判断为不透。→ 解决：四柱天干（年干、月干、日干、时干）都算透出。
3. **杂气格判断缺失**：月令是"戌"，但格局名是"正官格"而不是"杂气正官格"。→ 解决：判断月令是否为辰戌丑未，是则加"杂气"前缀。
4. **格局名错误**：如把"偏印格"写成"正印格"。→ 解决：根据十神名称精确匹配，不要模糊匹配。
5. **前端不展示**：后端算出来了，但前端没改，用户看不到。→ 解决：按验收标准，必须前端能看到。
