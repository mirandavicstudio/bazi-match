### 4.2 加载动画

#### 设计

```
文字提示："⏳ 正在匹配中..."
进度条：<progress> 或 div 模拟
动态数字：已匹配 X / 10000  （模拟，非真实进度）
```

#### 实现思路

由于后端是一次性返回结果（不是流式），**前端无法获得真实进度**。

两种方案：

| 方案 | 做法 | 优缺点 |
|------|------|--------|
| **方案 A：假进度条** | 用 setInterval 模拟进度 0→90%，等后端返回后跳 100% | 简单，但假 |
| **方案 B：后端 SSE/WebSocket** | 后端每处理 100 条汇报一次进度 | 真实，但后端要改造成异步流 |

**推荐方案 A**（MVP 阶段）：假进度条 + 实际耗时统计。

#### 假进度条实现

```
1. 点击"开始匹配" → state = 'loading'
2. 启动定时器：progress 从 0 到 90，每 30ms +1
3. 同时发起 axios POST /api/match
4. 请求返回后 → progress = 100，清除定时器
5. 停留 300ms 让用户体验"完成" → state = 'result'
```

#### Checklist

- [ ] 编写加载状态 Vue 模板（`v-if="state === 'loading'"`）
- [ ] 实现假进度条（ref 驱动，setInterval 更新）
- [ ] 发起 axios 请求（POST /api/match）
- [ ] 请求返回后清除定时器 + 进度 100%
- [ ] 显示实际耗时（毫秒 → 秒，保留 1 位小数）
- [ ] 加载状态下禁用所有交互（或显示遮罩层）

#### 错误处理

```
HTTP 400：表单验证失败 → 提示用户检查输入
HTTP 500：后端异常   → 显示"服务异常，请稍后重试"
网络超时：> 10s     → 显示"请求超时，请重试"
```

#### axios 调用封装

```javascript
async function doMatch() {
  try {
    const resp = await axios.post('http://localhost:8000/api/match', {
      birth_year: 2000,
      birth_month: 3,
      ...
    });
    result.value = resp.data;
    state.value = 'result';
  } catch (err) {
    alert('匹配失败：' + (err.response?.data?.detail || err.message));
  }
}
```

## 八、边界情况处理

|------|---------|

## 九、性能优化

| 优化项 | 做法 |
|--------|------|
| 后端一次返回完整结果 | 前端无需分页，1W 条遍历后端已完成 |
| 结果列表只渲染 Top-N（N≤20） | v-for 只渲染少量 DOM，性能无压力 |
| 弹窗详情内容懒渲染 | 只有点击"查看详情"才渲染弹窗内容（v-if 而非 v-show） |
| Tailwind CDN 生产环境 | 用构建版本（tailwindcss.com/docs/installation/play-cdn）—— 但 MVP 阶段 CDN 没问题 |

#### Checklist

- [ ] 确认 Top-N 默认 = 5，最大 = 20（防止用户输 10000 导致前端卡死）
- [ ] 弹窗用 v-if 而非 v-show（避免初始渲染开销）
- [ ] 如果后期数据量增大（> 1W 条），考虑后端分页返回

## 十、部署方案

### 开发环境

```
# 终端 1：启动后端
cd backend
python -m uvicorn main:app --reload --host 0.0.0.0 --port 8000

# 终端 2：启动前端（简单静态服务）
cd frontend
python -m http.server 8080
# 或直接用浏览器打开 index.html（但会有 CORS 问题，建议用 http.server）
```

### 生产环境（可选，MVP 不需要）

- 后端：uvicorn + systemd / supervisor 守护进程
- 前端：nginx 静态文件服务，反向代理 `/api` 到后端
- 或者用 **CloudStudio 部署**（WorkBuddy 有 `cloudstudio-deploy` skill）

## 十一、文件清单

```
frontend/
└── index.html    # 单文件，包含所有 HTML + CSS（Tailwind CDN）+ JS（Vue3 CDN）
```

是的，**只有一个文件**。这是刻意的选择：
- 无需构建工具（webpack / vite 都不需要）
- 双击 `index.html` 即可在浏览器打开（开发阶段）
- 部署时扔到任意静态文件服务即可
